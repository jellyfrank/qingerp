# Qing Dashboard

统一原生电子表格仪表板的浅灰画布、白色卡片、青绿色标题、表格底色及行距，适配旧式对象单元格和新式字符串单元格、绝对及单元格锚点图表。已安装 qing_web_ui 和 spreadsheet_dashboard 时自动安装，也可手工安装；不强制其他环境安装仪表板。

仅处理原生只读序列化展示副本，不修改已保存工作簿、公式、数据源、统计范围、筛选、权限及跳转链接。保留原生标题翻译、日期控件和移动端布局。宝鑫瑞专属的历史模型迁移、财务期间选择和工资归档适配不包含在本模块中。已由宝鑫瑞适配器标记的工作簿不再重复重排。

源于宝鑫瑞客户验证的展示规则，提取为免费版独立模块。主要布局针对原生仪表板，复杂定制工作簿应先在测试环境核验。
