# qing_web_ui

Provides the QingERP Odoo 20 backend theme and workflow-shell interface.

### 账号主题偏好

主题设置现在保存到当前账号，换浏览器登录或刷新后按后台偏好恢复。基础主题与玻璃外观在同一次保存中提交；恢复默认也同步到账号。此前只存于浏览器的选项不会自动覆盖后台，更新后请在主题设置中选择所需外观并点击一次“应用”。保存失败会提示并保留窗口。

右上角提供图标式主题快捷入口：点击后选择太阳（浅色）、月亮（深色）或显示器（跟随系统）。选择随当前账号保存，刷新及换浏览器后恢复；跟随系统会响应系统配色变化。切换只更新主题模式，保留强调色、密度、侧栏和商业外观；保存失败保留当前外观，处理中防止重复提交。内部用户可用，原生键盘、关闭和手机触控保留。商业版通过依赖基础模块直接复用这个入口。


列表左侧的勾选列在桌面收紧至32px，触屏保留44px点击区域。显示序号列使用较小的宽度和留白，并按记录总数的位数预留空间；商业主题直接复用。序号、分页、选择和业务字段保持原有处理。
