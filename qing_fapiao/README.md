# 公共开票接口

`qing_fapiao` 为开票服务商适配器提供统一协议、不可变任务、异步执行、回调审计及业务登记扩展点。
当前版本 `20.0.1.0`，面向正式 Odoo 20.0 Community。

## 模块边界

公共模块只依赖 Odoo 原生 `mail`，不依赖其他 Qing 业务模块、OCA 或具体开票服务商。
`qing_fapiao_<供应商>` 依赖公共模块，实现认证、提交、查询、票文件与回调验签。
业务衔接模块依赖公共模块，将已审批申请转成任务，并在开票后完成本地登记和额度转换。

首版协议支持普通及专用蓝字发票。输入按行保存数量、分类编码、税率、计价方式、不含税金额和税额；
输出保留服务商状态、票号、主体、金额及原始文件。红字申请和作废尚未实现。

## 使用

开票接口管理员可从“开票接口 → 服务商账号／开票任务”访问配置与任务。
安装具体适配器后，分别配置测试和正式账号；创建首个任务后，账号所属公司、适配器及环境不能再修改。销方税号可以修改，新任务使用当前税号，已有任务继续使用创建时保存的税号。
公共模块不允许直接手工创建任务，任务由业务流程通过扩展接口创建。

后台任务默认每分钟检查一次；已受理或结果未知的任务默认间隔五分钟查询。
发送前先独立提交“可能已发送”标记，调用超时或进程退出后只查询原请求。
服务商已开票但本地登记失败时使用“登记／重试登记”，不会重新开票。
未发送任务可以取消；已发送任务保留状态与审计记录。

## 取消任务

未发送的任务可直接取消。已发送且未完成的任务可取消自动处理，停止轮询并记录操作人和时间；保留真实服务商状态、原请求号和业务占用额度。它不撤销外部税票，也不允许重新开票。恢复查询继续使用原任务。取消期间到达的有效开票结果仍会保留，不能当作未开票。

系统管理员可删除已取消任务（包括已取消自动处理的未完成任务）及其审计事件。已开票或已登记任务不能删除，正在调用服务商的任务需等待本轮操作完成。删除本地任务不撤销外部开票、不自动重开，也不取消关联开票申请；重新开票前必须核实原订单。普通接口管理员没有删除权限，混合批量操作有一条不符合条件即全部拒绝。

顶部和列表显示“任务状态”：停止自动处理后为“已取消”；“服务商状态”独立保留原先的待确认状态，恢复查询后任务状态重新跟随服务商结果。

## 来源与旧数据迁移

本模块由 Solutions `mommy_fapiao`（20.0.1.6）移植而来，同一版权方以 LGPL-3 重新授权，模型更名为 `qing.fapiao.*`。
安装到仍装有 `mommy_fapiao` 的数据库时，`post_init_hook` 按原 ID 复制服务商、开票任务和审计事件，迁移消息、附件、关注者和活动，
把开票接口管理员加入新组，并停用 `mommy_fapiao` 的定时任务、服务商和菜单，避免同一张发票被重复提交。扩展模块新增的列由各自的迁移脚本调用
`import_legacy_columns` 补齐。
