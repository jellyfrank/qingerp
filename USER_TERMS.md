# QingERP 用户使用条款 / User Terms

## 安装信息

安装 `qing_base` 后，系统默认约每 6 小时通过 HTTPS 向 `service.qingsolution.com` 发送公司名称、系统网址（协议、主机及端口）、已安装模块总数、QingERP 模块数量、产品版本及随机实例标识；不会发送模块名称列表、用户资料、业务单据或数据库内容。中性化测试数据库不发送，克隆数据库会重置实例标识。

## Installation information

After `qing_base` is installed, the system by default sends the company name, system URL (scheme, host and port), installed module count, QingERP module count, product version and random instance identifier to `service.qingsolution.com` over HTTPS approximately every six hours. It does not send module names, user details, business records or database contents. Neutralized test databases do not report, and cloned databases receive a new instance identifier.
