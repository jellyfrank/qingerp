# odoo企业微信模块 用户手册

版本: 16.1.2
更新日期：2022-09-07

## 配置

在企业微信管理后台获取以下三个参数，并填写到需要使用企业微信的公司设置中。

* 公司id：企业微信中的公司唯一ID. (https://work.weixin.qq.com/wework_admin/frame#profile)
* AgentID: 企业微信中应用的AgentID
* Secret： 企业微信中应用的Secret

## 功能简介

### 扫码登录(OAuth)

使用手机APP扫码登录,需要进行以下配置:

* 企业微信后台-应用管理-设置-企业微信授权登录
* odoo-设置-OAuth提供方-企业微信, 设置好企业ID和应用ID(Client ID)

### 一键登录

如果企业微信用户在odoo中绑定了员工,并且员工信息也绑定了系统用户, 那么用户可以在手机端直接点击Odoo应用登录到odoo系统.

> 需要企业微信管理员首先在企业微信管理后台将App首页设置为http://{URL}/qing_wework/oauth

### 部门同步

定时任务同步部门

### 员工同步

部门设置里使用同步员工按钮同步员工

### 应用消息

本模块支持多种消息类型，支持内嵌URL直接打开odoo内的网页。
