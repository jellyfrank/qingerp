企业微信基础版 / WeWork Base

将企业微信组织、登录和消息能力接入 Odoo 日常业务。

Connect WeWork organization, sign-in, and messaging capabilities to daily Odoo operations.

Odoo 20.0 WeWork Custom App LGPL-3
企业微信基础版帮助企业在 Odoo 中统一维护企业微信配置、组织与员工同步、扫码登录和业务消息发送，并为企业微信自建应用提供菜单与工作台管理能力。
WeWork Base centralizes WeWork configuration, department and employee synchronization, QR-code sign-in, and business messaging in Odoo. It also manages menus and workbenches for WeWork custom applications.

核心能力 / Core Capabilities

组织与员工同步 / Organization Sync

从企业微信同步部门与员工，并维护 Odoo 员工和企业微信账号的对应关系。

Synchronize departments and employees from WeWork while maintaining the Odoo-to-WeWork identity binding.

扫码登录 / QR-Code Sign-In

通过企业微信 OAuth 将已绑定员工带回 Odoo，减少账号密码登录步骤。

Use WeWork OAuth to bring bound employees into Odoo without a separate password flow.

消息、模板与媒体 / Messages and Media

在 Odoo 中维护消息模板、文件媒体和机器人消息，将业务提醒发送至企业微信。

Maintain message templates, file media, and robot messages in Odoo for WeWork business notifications.

自建应用管理 / Custom App Management

配置企业微信自建应用菜单和工作台展示，为员工提供移动端业务入口。

Configure custom-app menus and workbenches to provide mobile business entry points.

产品截图 / Product Screens

企业微信配置 / WeWork Configuration

集中配置 CorpID、AgentID、连接测试和同步策略。 / Configure credentials, test connectivity, and set synchronization policies in one place.

组织同步 / Organization Synchronization

同步企业微信部门和员工。 / Synchronize WeCom departments and employees.

机器人消息 / Robot Messages

将业务消息推送到企业微信。 / Send business notifications to WeCom.

媒体文件 / Media Files

上传、下载和管理企业微信媒体。 / Upload, download, and manage WeCom media files.

应用菜单 / Application Menus

配置企业微信自建应用菜单。 / Configure WeCom custom application menus.

使用流程 / Workflow

  1. 创建企业微信记录，填写自建应用凭据并测试连接。 / Create the WeWork record, enter custom-app credentials, and test the connection.
  2. 同步部门和员工，确认员工与企业微信账号的绑定关系。 / Synchronize departments and employees, then confirm identity bindings.
  3. 按需启用扫码登录、消息模板、机器人与媒体文件。 / Enable QR-code sign-in, templates, robots, and media as needed.
  4. 配置自建应用菜单或工作台，并向员工发布业务入口。 / Configure the custom-app menu or workbench and publish business entry points.

使用条件 / Requirements

需要 Odoo 20.0、已启用的企业微信自建应用，以及访问通讯录、OAuth、消息、菜单和媒体接口所需的权限。服务器环境还需要安装 manifest 中声明的 Python 依赖；智能机器人 WebSocket 模式另需安装 websocket-client。
Requires Odoo 20.0, an enabled WeWork custom application, and permissions for organization, OAuth, messaging, menu, and media APIs. The server must also provide the Python dependencies declared in the manifest; intelligent-bot WebSocket mode additionally requires websocket-client.
