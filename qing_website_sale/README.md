# Qing Website Sale

在 **网站 → 配置 → 设置 → 电子商务** 中勾选 **登录后可见商品价格**。
该选项按网站保存，默认关闭。

- 开启：访客可以浏览商品，商品卡片和详情显示“登录｜注册 查看价格”。
- 登录后：门户客户和内部用户按原生价目表、税率、折扣和变体规则看到价格并购买。
- 注册入口只在网站允许公开注册时显示；登录或注册后返回原页面。
- 商品变体、单位附加价、搜索、动态推荐和商品结构化数据不公开真实价格。
- 开启时访客需先登录再加入购物车或进入购物车和结账，避免通过购物车看到价格。
- 关闭后恢复原生商城行为；其他网站不受影响。

依赖 Odoo 20.0 的 `website_sale` 和 QingERP 的 `qing_base`，安装后使用。
本模块继承原生商城模板；完全替换价格模板的第三方主题需要独立适配。

设置优先选择当前公司的默认网站；若该公司没有网站，则选择当前请求的网站（后台 `host_id` 或前台 `website_id`），无请求上下文时使用系统默认网站。已有网站选择保持；网站为空时不能勾选价格选项，避免保存到空目标。
