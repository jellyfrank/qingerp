# 配置 AI 业务操作

系统管理员打开 **青云 AI → 技能 → 配置操作**，即可把业务操作加入当前技能。
工具明细菜单仍只在开发者模式显示；员工使用智能体时不需要进入工具配置。

## 通用操作

1. 模板选择“选择模型与操作”，选择业务模型，例如“联系人标签”。
2. 勾选查询、详情、统计、创建、修改、归档、恢复或删除。
3. 默认由系统在运行时发现调用员工可读的字段；如需进一步收窄，可关闭“自动发现所有可读字段”后手选查询、分组和指标字段。创建和修改仍必须单独选择可写字段，例如名称、颜色。
4. 按需设置固定记录过滤条件、查询上限和可使用的用户组。留空用户组表示所有内部用户，但仍受原生业务权限限制。
5. 点击“配置操作”。每个勾选项生成一个工具，自动生成标识、调用参数和说明，并加入所选技能。
6. 将技能赋予智能体，即可在会话中请求查询或准备修改。查询结果包含记录 ID；详情和修改可使用这个 ID。

无需编写 Python 或 JSON Schema。高级选项允许管理员配置 JSON 固定字段值；AI 不能覆盖固定值。
可写字段目前支持普通文本、数字、布尔、选项、日期、日期时间和多对一关联。
关联值使用已有记录 ID；一对多/多对多写入、任意方法调用不在通用配置范围内。

## 所有可读字段

工具明细的“字段与范围”和配置操作向导均提供“自动发现所有可读字段”开关，默认开启。
开启后，按实际调用员工的字段权限动态开放工具支持的全部字段（含后续新增字段），查询、关联字段过滤和分组无需逐一勾选。
关闭后恢复使用原来的手选字段列表；已有工具不会自动扩大字段范围。
适用字段类型为文本、数字、布尔、选项、日期、日期时间和多对一关联。
二进制、HTML、JSON、一对多、多对多等当前不支持的类型，以及密钥、令牌、密码等敏感字段仍排除。
某些计算字段依赖员工无权读取的其他业务数据；全部字段模式会跳过这些字段，并在结果中列出不可读取字段，其他字段正常返回。
可写字段独立配置，开关不会扩大修改权限。

## 多步工具推理

业务请求由模型一次选择一个技能中的工具。应用执行后会把已校验的结果交回同一规划任务，模型可继续查询关联记录、读取详情、统计或生成最终回答。例如“山东省客户”可先按 `state_id.name` 查询，而无需为省份单独配置字段；创建报价时可先查客户和产品，再准备草稿预览。

每个任务最多进行 6 轮模型规划、10 次工具调用并在 120 秒内结束。重复调用同一成功工具会被阻止；工具不支持某个条件时，模型必须补充查询或向用户提问，不能删除条件后扩大结果。规划状态保存在客户数据库中，页面刷新或重新打开会话后可以继续。所有查询仍在当前员工权限下执行，所有写入仍停在人工确认预览。

## 客户和销售订单模板

安装 `qing_ai_sale` 后，向导提供：

- **客户管理**：客户查询及数量统计、创建客户、编辑客户。
- **销售订单**：客户与产品查询、订单查询及数量统计、创建报价草稿。

这些模板直接复用现有工具，不重复创建，不改变其用户组限制，也不重置已配置的技能。
客户模板保留 QingERP 客户身份和维护权限；报价模板使用原生报价行、价格和税额计算。
销售订单、采购、库存、财务和制造单据的写入使用业务模板，通用操作不直接变更单据状态。

## 确认和权限

查询立即执行；创建、修改、归档、恢复和删除先生成预览，由用户确认后执行。
预览阶段不提前调用业务模型的 `create/write/unlink`。
确认绑定发起人、当前公司、工具配置和目标记录，15 分钟内有效。
记录或配置变化、权限被撤销时必须重新生成预览；重复点击同一确认不会再次执行。
执行失败会回滚本次写入。

业务操作使用当前员工身份，遵守 ACL、记录规则、字段权限及当前公司范围。
默认过滤与 AI 提供的过滤取交集，查询最多返回 100 条，写入每次只作用于一条记录。
系统配置、用户权限、密钥等技术模型和敏感字段不能作为通用工具开放。

## 升级

升级 `qing_ai`；已安装销售功能时，同时升级 `qing_ai_sale`。
已有工具标识、技能关联、销售预览记录保持兼容。
模型调用沿用 Qing AI 已配置的国内或国际供应商，客户自行承担其模型费用；此功能不依赖 IAP。

## 分组统计

在配置操作向导勾选“分组统计”；自动字段模式下无需预先选择分组字段和数值指标，模型会从当前员工可读且可存储的字段中选择。关闭自动字段模式后，仍可手选固定字段白名单。
例如选择联系人、按国家分组，即可统计各国家记录数量。
免费版只提供通用引擎，不默认将联系人判定为客户；客户口径应通过记录过滤设置。
商业版 `qing_ai_sale_enterprise` 提供无需逐项配置的客户和销售统计模板。

- 分组字段必须是当前用户可读、可存储的文本、布尔、整数、选项、日期、日期时间或多对一字段，每次最多三个。
- 数值指标可选整数、小数和金额字段，每次最多七个。支持求和、平均值、最小值、最大值，默认计数。
- 未选择数值指标时只计数。分组、指标字段同时允许用于收窄查询条件；其他筛选字段仍由“可读字段”配置。
- 日期支持按天、周、月、季度、年分组，默认按月，使用调用者时区。
- 金额指标要求将对应币种字段加入可读字段，系统会自动追加币种分组，避免不同币种直接相加。
- 后端执行原生 `_read_group`，遵守模型、字段、记录及当前公司权限；不受明细查询上限影响。
- 查询上限在统计操作中表示最多显示的组数，超出时明确提示；不会把前若干组冒充完整结果。
- 报告直接返回 Markdown 表格、当前公司和完整匹配记录数；未设置字段独立成组。
- 统计工具可参与受限的多轮规划；仍不执行任意 SQL、任意 Python 方法或未经确认的写入。
